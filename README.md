# OpenVoice Windows (Preserved Build)

This repository contains a Windows‑friendly build of **OpenVoice**, based on the original open‑source project.  
The original version was Linux‑only, so this build removes Linux‑specific dependencies and includes only the files required to run OpenVoice on Windows.

## What This Version Does
- Runs fully on Windows without WSL or Linux tools  
- Removes Linux‑only scripts, packages, and environment files  
- Includes a portable Windows‑ready folder structure  
- Preserves the original open‑source code and license  
- No proprietary or paid models included

## Why This Exists
The original OpenVoice project did not provide a Windows build.  
This repo preserves a working Windows version so users can continue using the tool even if the original source becomes unavailable.
